# 🧬 MedBioInfo Blog – Applied Bioinformatics Course

Welcome to my personal learning blog for the **Applied Bioinformatics** course, part of the [MedBioInfo graduate school](https://www.medbioinfo.se/) at **SLU**.

This blog is built with [Quarto](https://quarto.org/) and documents my **daily reflections, what I learned from the excersices, and more** in applied bioinformatics.

---

## 📘 About This Blog

Each post captures a day in the course and includes:
- 🧠 What I learned
- 🔬 Key concepts and tools
- ✍️ Reflections and challenges

This serves both as:
- A **learning diary** for myself  
- A wat for me to practice how to use Quarto
  
## 🚀 Technologies Used

- **[Quarto](https://quarto.org/)** for site generation and publishing
- **Markdown** for daily posts
- **Git + GitHub** for version control and hosting
- **MultiQC**, **ggplot2**, **Nextflow**, **nf-core**, **R**, **bash**, etc. as part of the course
